# דשבורד דיגיטל – רשות החדשנות

דשבורד סטטי (HTML/CSS/JS) עם נתוני Google Analytics ו־Google Search Console.

## מבנה הקבצים

| קובץ | מה יש בו |
|---|---|
| `index.html` | מבנה הדף: הכותרת, הטאבים והמסכים |
| `css/style.css` | כל העיצוב: צבעי הרשות, פונט Heebo, תצוגת מובייל ומצב כהה |
| `js/app.js` | הלוגיקה: טאבים, בחירת תקופה, גרפים, טבלאות וסוכן ה־AI. בראש הקובץ נמצאים נתוני Google Analytics (לפי רבעון) והביטויים והדפים המובילים |
| `js/data.js` | נתוני Search Console יומיים (תאריך, קליקים, חשיפות, מיקום) |
| `assets/rego-logo.png` | הלוגו של ReGo (רקע שקוף) |

הגרפים משתמשים בספריית d3, שנטענת מ־cdnjs.

## העלאה ל־GitHub Pages

1. יוצרים repository חדש ומעלים את כל הקבצים והתיקיות כמו שהם (index.html בתיקייה הראשית).
2. Settings ← Pages ← Source: `Deploy from a branch`, ענף `main`, תיקייה `/ (root)` ← Save.
3. אחרי דקה־שתיים הדף זמין בכתובת `https://<user>.github.io/<repo>/`.

## הערות

- סוכן ה־AI ("שאלו את הנתונים") פועל רק כשהדף פתוח בתוך Claude. מחוץ לו הכפתור מוסתר.
- הנתונים נכונים ל־28.10.2026. עדכון = החלפת `js/data.js` ונתוני Analytics בראש `js/app.js`.
- ב־repository ציבורי, כל מי שיש לו את הקישור יכול לראות את הנתונים.
